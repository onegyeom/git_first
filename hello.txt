안녕하세요 오늘은 두번째 시간입니다.
git add . : 현재파일을 기록하고 저장해달라고 git한테 명령
git init : 폴더를 만들고 git을 그 안에 넣어서 말한다
git add 파일명.확장자 : 내가 원하는 파일만 저장하고 싶다
git commit -m "오늘처음 만든 git" : 저장하고 나면 이 파일이 어떤 작업을
 했는지 기록 쌍따옴표로 내용 작성
git config --global user.name "이름" ,
git config --global user.email "이메일주소": 
git 파일을 수정하고 기록할 때 누가 작성하고 올렸는지 확인하기 위해서 사용자 설정 

오늘 오후에 들어갈 내용은
좋은 커밋 작성법 : commit -m "내가 지금 한 작업내용"
git log : git 기록 조회
git status : git 현재 상태조회

git branch -M main : 현재 내 컴퓨터 작업공간의 이름을 변경
git push -u origin main : origin 주소로 온라인에 업로드
